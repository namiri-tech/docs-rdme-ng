## DigiTax Nigeria API update

Make the local government and state optional in the API when creating a party and detailed invoice.

**Why**?<br />This update is intended to support customers who currently lack these details for their clients and need additional time to gather the information. It follows a directive issued by FIRS.

**Note**: This field will become mandatory once we receive the official update from FIRS. A 30-day notice will be issued to all customers before enforcement.
